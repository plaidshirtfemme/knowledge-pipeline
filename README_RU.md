# Knowledge Pipeline

Python-пайплайн для автоматического превращения YouTube-видео и статей в структурированные Markdown-заметки в Obsidian — с AI-обогащением, семантическим поиском и умной классификацией по папкам.

Создан как личный инструмент управления знаниями. Демонстрирует обработку **704 URL в автономном режиме** с автоматическим восстановлением после прерываний.

## Что делает

1. **Принимает** URL (YouTube-видео или статья)
2. **Извлекает** транскрипт через youtube-transcript-api / yt-dlp или текст статьи через trafilatura
3. **Обогащает** через Claude Haiku API — генерирует заголовок, краткое содержание, ключевые идеи, практические шаги, инсайты, теги и классифицирует в нужную папку vault
4. **Записывает** структурированную Markdown-заметку с YAML frontmatter в правильную подпапку Obsidian
5. **Сохраняет** векторный эмбеддинг в DuckDB для будущего семантического поиска

## Ключевые инженерные решения

**Промпт-инжиниринг для классификации.** Claude классифицирует каждую заметку в одну из ~40 папок, используя подробные описания и файл `folder_examples.yml` с YES/NOT примерами — итерировались на реальных ошибках классификации в продакшне. Few-shot примеры подгружаются динамически при каждом вызове.

**Устойчивое извлечение с YouTube.** YouTube агрессивно ограничивает запросы с VPN-адресов (особенно актуально для России). Решение — fallback-цепочка: youtube-transcript-api (основной) → yt-dlp с Node.js n-challenge → заметка только по описанию с флагом `needs_review: true`. Исключение `IpBlocked` даёт понятное сообщение с действием вместо краша. Поддержка `cookies.txt` для снижения частоты блоков.

**Идемпотентная пакетная обработка.** `--batch urls.txt --chunk-size 20 --pause 10` обрабатывает сотни URL часами. Уже обработанные URL пропускаются через поиск `source_url` во frontmatter — безопасно перезапускать после любого прерывания: сон, краш, смена VPN.

**Параллельная обработка статей.** `--parallel N` запускает статьи через `ThreadPoolExecutor` (рекомендуется 3–5 потоков). Видео всегда последовательно — YouTube блокирует параллельные запросы с одного IP. Результаты записываются thread-safe через общий lock.

**Повторное обогащение без повторного скачивания.** `reenrich.py` запускает Claude-обогащение заново на существующих заметках для обновления классификации, тегов и текстовых полей — без повторного скачивания источника. Поддерживает `--folder KEY` для обработки одной папки и `--limit N` для тестирования.

## Масштаб

Обработан **батч из 704 YouTube URL** в автономном режиме:
- ✓ 258 новых заметок создано
- → 97 пропущено (уже существовали — идемпотентность работает)
- ✗ 205 пропущено (видео > 40 мин, настраиваемый лимит)
- ✗ 96 IP-блоков YouTube (rate limiting через VPN, обработаны gracefully со структурированными логами)
- ✗ 48 без извлекаемого текста (нет субтитров + нет описания)

## Пример заметки

Каждая заметка — Markdown-файл с YAML frontmatter:

```yaml
---
note_id: 20260618-4508
title: 'UI паттерны: стандартизированные элементы интерфейса'
source_url: https://www.youtube.com/watch?v=4mVJvM1gqHs
source_type: video
published: "2019-02-27"
tags:
- ux_ui_design
- ui_patterns
- interaction_design
- dark_patterns
---

## Кратко
Введение в UI паттерны — стандартизированные решения типовых задач проектирования интерфейсов.

## Ключевые мысли
- UI паттерн — переиспользуемое решение для типовой задачи...

## Инсайты
- Dark patterns существуют потому что работают краткосрочно...
```

## Стек

- **Python 3.13** — ядро пайплайна
- **Anthropic Claude Haiku** — AI-обогащение (структурированное извлечение JSON из неструктурированного текста)
- **youtube-transcript-api + yt-dlp** — извлечение субтитров YouTube с fallback-цепочкой
- **trafilatura** — извлечение текста статей
- **sentence-transformers** (`paraphrase-multilingual-MiniLM-L12-v2`) — многоязычные эмбеддинги
- **DuckDB** — локальное векторное хранилище
- **PyYAML** — генерация frontmatter, совместимого с Obsidian

## Структура проекта

```
knowledge-pipeline/
├── ingest.py              # CLI-оркестратор, пакетная обработка, логирование
├── router.py              # Определение типа URL (video / article)
├── enrich.py              # Обогащение через Claude API, промпт-инжиниринг
├── note_writer.py         # Генерация Markdown + frontmatter, раскладка по vault
├── store.py               # Векторное хранилище DuckDB
├── config.py              # Таксономия папок vault (~40 папок), настройки
├── exceptions.py          # Типизированные исключения (IPBlockedError, VideoTooLongError и др.)
├── extractors/
│   ├── video.py           # Извлечение транскрипта с fallback-цепочкой (YouTube, Vimeo, Rutube, VK)
│   └── article.py         # Извлечение текста статей (определяет встроенные видео)
├── folder_examples.yml    # Few-shot YES/NOT примеры для классификации Claude
├── reenrich.py            # Переклассификация существующих заметок с обновлёнными промптами
├── fix_tags.py            # Нормализация тегов по всему vault
├── analyze_tags.py        # Анализ распределения тегов
└── logs/                  # Логи каждого запуска + отчёты ok/failed по URL (в .gitignore)
```

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Заполни ANTHROPIC_API_KEY и VAULT_PATH в .env
```

## Использование

```bash
# Одиночный URL
python ingest.py https://youtube.com/watch?v=...

# Пакетная обработка из файла (последовательно)
python ingest.py --batch urls.txt --chunk-size 20 --pause 10

# Пакетная обработка с параллельными статьями (рекомендуется 3–5 потоков)
python ingest.py --batch urls.txt --chunk-size 20 --pause 10 --parallel 4

# Повторное обогащение существующих заметок (сначала dry run)
python reenrich.py --limit 5
python reenrich.py --apply

# Запуск тестов
python -m pytest tests/
```
