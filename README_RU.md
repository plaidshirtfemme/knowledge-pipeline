# Knowledge Pipeline

Python-пайплайн для автоматического превращения YouTube-видео и статей в структурированные Markdown-заметки в Obsidian — с AI-обогащением, векторной базой под семантический поиск и умной классификацией по папкам.

Создан как личный инструмент управления знаниями. Демонстрирует обработку **704 URL в автономном режиме** с автоматическим восстановлением после прерываний.

## Что делает

1. **Принимает** URL (YouTube-видео или статья; Vimeo / Rutube / VK — экспериментально, через yt-dlp fallback)
2. **Определяет** тип источника (видео / статья) — router.py
3. **Извлекает** транскрипт через youtube-transcript-api / yt-dlp или текст статьи через trafilatura
4. **Обогащает** через Claude Haiku API — модель возвращает структурированный JSON:
   - `summary` — краткое содержание
   - `concepts` — ключевые идеи (заложены под семантический поиск)
   - `instructions` — шаги (для обучающих материалов)
   - `insights` — мысли, заслуживающие особого внимания
   - `entities` — конкретные сущности: люди, инструменты, алгоритмы (для фильтрации и графов)
   - `tags` — теги (для фильтрации и графов)
   - `folder` — модель сразу **определяет** нужную папку vault (~50 папок)
5. **Записывает** Markdown-заметку с YAML frontmatter в выбранную папку Obsidian
6. **Сохраняет** векторный эмбеддинг в DuckDB — векторная база под будущий семантический поиск

## Ключевые инженерные решения

**Промпт-инжиниринг для классификации.** Claude классифицирует каждую заметку в одну из ~50 папок, используя подробные описания и файл `folder_examples.yml` с примерами классификации (YES/NOT) — итерировались на реальных ошибках классификации в продакшне. Примеры подгружаются динамически при каждом вызове.

**Устойчивое извлечение с YouTube.** YouTube агрессивно ограничивает запросы с VPN-адресов (особенно из России). Решение — fallback-цепочка: youtube-transcript-api (основной) → yt-dlp (загрузка субтитров) → если текста нет вовсе, заметка собирается только из описания и помечается `needs_review: true` для ручной проверки. Исключение `IpBlocked` даёт понятное сообщение с действием вместо краша. cookies.txt технически опциональны, но на практике (из России через VPN) без них YouTube блокирует почти все запросы — для реального батча они нужны.

**Идемпотентная пакетная обработка.** `--batch urls.txt --chunk-size 20 --pause 10` обрабатывает сотни URL часами. Уже обработанные URL пропускаются через поиск `source_url` во frontmatter — безопасно перезапускать после любого прерывания: сон, краш, смена VPN.

**Параллельная обработка статей.** `--parallel N` запускает статьи через `ThreadPoolExecutor` (рекомендуется 3–5 потоков). Видео всегда последовательно — YouTube блокирует параллельные запросы с одного IP. Результаты записываются thread-safe через общий lock.

**Повторное обогащение без повторного скачивания.** `scripts/reenrich.py` запускает Claude-обогащение заново на существующих заметках для обновления классификации, тегов и текстовых полей — без повторного скачивания источника. Поддерживает `--folder KEY` для обработки одной папки и `--limit N` для тестирования.

## Масштаб

Обработан **батч из 704 YouTube URL** в автономном режиме:
- ✓ 258 новых заметок создано
- → 97 пропущено (уже существовали — идемпотентность работает)
- ✗ 205 пропущено (видео > 40 мин, настраиваемый лимит)
- ✗ 96 IP-блоков YouTube (rate limiting через VPN, обработаны gracefully со структурированными логами)
- ✗ 48 без извлекаемого текста (нет субтитров + нет описания)

## Пример заметки

Каждая заметка — Markdown-файл с YAML frontmatter:

```yaml
---
note_id: 20260618-4508
title: 'UI паттерны: стандартизированные элементы интерфейса'
source_url: https://www.youtube.com/watch?v=4mVJvM1gqHs
source_type: video
published: "2019-02-27"
tags:
- ux_ui_design
- ui_patterns
- interaction_design
- dark_patterns
---

## Кратко
Введение в UI паттерны — стандартизированные решения типовых задач проектирования интерфейсов.

## Ключевые мысли
- UI паттерн — переиспользуемое решение для типовой задачи...

## Инсайты
- Dark patterns существуют потому что работают краткосрочно...
```

## Стек

- **Python 3.13** — ядро пайплайна
- **router.py** — определение типа URL (видео / статья)
- **trafilatura** — извлечение текста статей
- **youtube-transcript-api + yt-dlp** — извлечение субтитров видео с fallback-цепочкой
- **Anthropic Claude Haiku** — AI-обогащение (структурированное извлечение JSON из неструктурированного текста)
- **PyYAML** — генерация frontmatter, совместимого с Obsidian
- **sentence-transformers** (`paraphrase-multilingual-MiniLM-L12-v2`) — многоязычные эмбеддинги
- **DuckDB** — локальное векторное хранилище

## Структура проекта

```
knowledge-pipeline/
├── ingest.py              # CLI-оркестратор, пакетная обработка, логирование
├── router.py              # Определение типа URL (видео / статья)
├── extractors/
│   ├── video.py           # Извлечение транскрипта с fallback-цепочкой (YouTube; Vimeo/Rutube/VK — экспериментально)
│   └── article.py         # Извлечение текста статей
├── enrich.py              # Обогащение через Claude API, промпт-инжиниринг

├── config.py              # Таксономия папок vault (~50 папок), настройки
├── exceptions.py          # Типизированные исключения (IPBlockedError, VideoTooLongError и др.)
├── folder_examples.yml    # Примеры классификации (YES/NOT) для выбора папки Claude

│   ├── analyze_tags.py    # Анализ распределения тегов
```

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Заполни ANTHROPIC_API_KEY и VAULT_PATH в .env
```

### cookies.txt (для YouTube)

YouTube блокирует запросы с VPN-адресов. Чтобы этого избежать, положи в корень проекта файл `cookies.txt` в формате Netscape (экспортируется расширением браузера, например «Get cookies.txt», будучи залогиненным в YouTube). Файл в `.gitignore` — не коммить его. Технически опционален, но на практике без него батч упрётся в IP-блоки почти на каждом запросе.

### urls.txt (для батча)

Список URL для пакетной обработки — по одному на строку:

```
https://www.youtube.com/watch?v=XXXXXXXXXXX
https://www.youtube.com/watch?v=YYYYYYYYYYY
https://habr.com/ru/articles/123456/
```

## Использование

```bash
# Одиночный URL
python ingest.py https://youtube.com/watch?v=...

# Пакетная обработка из файла (последовательно)
python ingest.py --batch urls.txt --chunk-size 20 --pause 10

# Пакетная обработка с параллельными статьями (рекомендуется 3–5 потоков)
python ingest.py --batch urls.txt --chunk-size 20 --pause 10 --parallel 4

# Повторное обогащение существующих заметок (сначала dry run)
python scripts/reenrich.py --limit 5
python scripts/reenrich.py --apply

# Запуск тестов
python -m pytest tests/
```
